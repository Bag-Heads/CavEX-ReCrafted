Isabella II -- optional texture pack for CaveWii_v2
====================================================

What this is
------------
This folder is an OPTIONAL texture pack. It holds the Isabella II art that
CaveWii_v2 used as its default until 2026-10-10, packaged so you can pick it
as a pack of its own. It is not the bundled default: the game uses its own
Earth & Ash art under assets/ unless you select this pack.

This is a PARTIAL pack. It contains these 11 Isabella II images:

  terrain.png, particles.png, gui/items.png, terrain/sun.png,
  terrain/moon.png, environment/clouds.png, gui/crafting.png,
  gui/furnace.png, gui/gui.png, gui/icons.png, gui/inventory.png

plus its own pointer.png (an ivory glove) and font/default.png. Those two
are NOT Isabella II files: they are original CaveWii artwork made for this
pack in Isabella's style and dedicated under CC0 1.0 (2026-10-11).

Its anim.png (fire, lava, water, flowing water, portal) moves exactly like
Minecraft Beta 1.7.3's own animated textures, recoloured with colours taken
from Isabella II's water, lava, portal and fire tiles, and its ice cells are
Isabella II's own ice tile. It is therefore an adapted (modified) Isabella II
file, under the same CC BY 3.0 licence and credit below.

It also carries two files DERIVED from Isabella II (modified, under the same
CC BY 3.0 licence and credit below):

  gui/menu-background.png  An in-game render of CaveWii's own terrain generator
      (seed 42, fixed camera, noon, clear weather) drawn with Isabella II's
      terrain, sky and cloud textures, cropped and scaled to 1024x576 for the
      title screen. Isabella II pixels appear in it, so it is a modified
      (derived) work.
  mob/char.png  The player figure shown in the inventory: an original 64x32
      CaveWii skin drawn from scratch, adapted to Isabella II's palette and
      shading. It is not claimed to be Bonemouse's own skin.

Every file it lacks (mobs, armor, chest screens, font, sounds and so on)
falls back, file by file, to the bundled default art in assets/.

How to pick it
--------------
1. Keep this folder at sd:/texturepacks/isabella-ii/ (where the release zip
   puts it).
2. Open the Texture Packs screen in CaveWii_v2. The pack is listed as
   'isabella-ii' (the screen lists up to 31 pack folders).
3. Select it. To go back, select the default pack on the same screen.
