# W01 pre-change baselines

Source revision: `cd687b6a8aa5e24832afbaf53aeca954be7fa075`.

`windup_render_baseline.c` is the unmodified `source/graphics/render_entity.c`
from that revision. It is a frozen reference compiled only by
`test_mob_windup_render.py`, with recording graphics/displaylist doubles.
The test compiles the candidate model code intact, records all 60 walk frames
at three stride amplitudes in two view matrices, and compares disabled-cue
matrices, vertices, lighting, UV, texture and graphics-state inputs byte for
byte. Active half/full poses and the actual monster render dispatch are also
checked. These doubles do not prove GPU output, native visibility/depth,
controller usability or 480i readability.

`mob_windup_sim_baseline.txt` is a 480-tick tape generated by
`test_mob_windup_cue --sim-trace <file>` with that revision's original
`entity_monster.c` object substituted at link time. The shared engine objects
and headers were the W01 build; its other simulation code is unchanged.
Four species each run 120 ticks in a seed-4242 superflat midnight world;
the fixture pins position/velocity each tick and exercises opening/sustained
attacks, out-of-reach/re-entry, target death/recovery, and lethal damage/death ticks. It records health,
attack counters, aggro, AI state, float/double motion, knockback, wolf target,
and the entity/world simulation RNG seeds, Gaussian-cache-valid bits and valid cached values.
Ordinary MOVE fields and their publication ticks, plus the gate-valid bit and
resend timer, are recorded too; only the new cue metadata and cosmetic audio
RNG are excluded. Cue-only updates carry no pre-existing render input.
The default CTest compares the candidate's real ticks with this tape.
This is a behavior-preservation reference, not an independent Beta oracle.

Floating fields use canonical 16-digit IEEE double bit patterns, including
float fields widened exactly to double. This avoids `%a` output differences
between C libraries without rounding or a numeric tolerance. The original
CRLF `%a` tape SHA256 was
`8a12133181f318c375c934df09f387664ebdc6c2182c7400ffc5b2710e6815aa`.
The comparison opens both text streams in text mode for portable newline
normalization. Regenerate only from the stated pre-change mob source, never
from a candidate to make a mismatch pass. The generation/link commands and
before/after tapes are retained in `tmp/jobs/windup-cue-1005/`.
